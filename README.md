## About

Chaos mod GD adds random events every time the timer hits 0. The events vary from jumpscares to speed increases.
You can change the countdown time in the settings.

If you find a bug, use the debug features to understand the bug in detail and report it to me in github issues!

## Events

Chaos Mod GD v1.0.3 currently has these events:
 * speed x0.5
 * speed x1.5
 * speed x2
 * gravity low
 * gravity high
 * reverse controls
 * size mini
 * jump delay
 * soggy jumpscare
 * doggie jumpscare
 * invert colors
 * shake screen
 * high pitch
 * low pitch
 * pause game
 * snow screen
 * fps 20

Expect to see more events in future updates!
